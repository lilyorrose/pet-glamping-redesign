# 풀글램핑&펫글램핑 — 홈페이지 리뉴얼 결과물

포항 구룡포·호미곶 **풀글램핑&펫글램핑**(http://www.pet-glamping.kr/)의 기존 홈페이지를 다시 만든 결과물입니다.
손님용 페이지(`index.html`)와 사장님 전용 통제실(`admin.html`) 두 개로 이루어져 있습니다.

---

## 2.그대로 열어 보는 방법

1. 이 폴더에서 명령 창을 열고 아래를 실행합니다.
   ```
   python3 -m http.server 8080
   ```
2. 브라우저에서 `http://localhost:8080/index.html` (손님), `http://localhost:8080/admin.html` (사장님)을 엽니다.
   - `index.html`을 파일로 직접 열어도 대부분 동작하지만, 저장(브라우저 기억) 기능은 위처럼 주소로 열 때 확실합니다.

## 3. 실제로 올릴 때

- `index.html`, `admin.html`, `assets/` 폴더를 그대로 호스팅에 올리면 됩니다. 서버 프로그램은 필요 없습니다(정적 사이트).
- 카페24·가비아 등 기존 호스팅의 같은 위치에 덮어쓰면 주소는 그대로 유지됩니다.
- 사장님이 통제실에서 바꾼 내용을 **모든 손님에게** 보이게 하려면: 통제실 → `저장·설정` → **site-data.js 내려받기** → 받은 파일을 `assets/js/site-data.js` 자리에 덮어쓰기.

## 3-2. 객실 상세 화면 (2026-11-22 새로 만든 풀폭 화보)

- 객실 카드나 사진을 누르면 `#roomModal`이 화면 전체로 열립니다. 맨 위 대표 사진은 가로 100%·세로 모바일 74svh / 데스크톱 82vh로 화면을 채웁니다.
- 사진 넘기기: 손가락 스와이프, 좌우 화살표, 아래 점, 키보드 ←/→. 상단 바에 `01 / 08` 번호와 지금 사진의 이름(오션뷰 욕조·침실 등)이 나옵니다.
- 대표 사진 아래로 같은 사진들이 1열 풀폭으로 이어집니다(모바일 4:3, 데스크톱 16:9). 누르면 원본 1920px 라이트박스.
- 사진 파일: `assets/img/r/{객실}/01.jpg…`(1920px 원본) + `th/`(900px, 목록 카드용). 사진 순서와 캡션은 `assets/js/site-data.js`의 `rooms[].photos.all`·`photos.caps`에서 바꿉니다.
- `soft.html`도 같은 화면을 씁니다(글씨 색·굵기만 다름).

## 4. 사장님 통제실 사용법

- 주소: `사이트주소/admin.html`
- 처음 비밀번호: **2580** (통제실 → `저장·설정`에서 바꿀 수 있습니다)
- 글씨 크기: 화면 위 `보통 / 크게 / 아주 크게` — 누르면 바로 커지고, 그 휴대폰에 기억됩니다.
- 할 수 있는 일
  - 체험단 예약 확인 → **[오케이·승인하기]** 한 번
  - 확정 안내 → **[안내문 복사]** → 카카오톡에 붙여넣기 (문자 요금 없음), 휴대폰에서는 **카톡으로 보내기**
  - 후기 등록 여부·마감일(D-day) 확인, 검색 노출 체크
  - 블로그·인스타·네이버 예약·떠나요 바로 열기
  - 이벤트 배너 켜기/끄기, 객실 마감, 맨 위 공지 문구 수정 → 손님 페이지에 즉시 반영
  - 홈페이지 맨 아래에 띄울 후기(클립·블로그·인스타) 고르기 / 새 후기 링크 넣기

### 5-1. 첫 화면 사진 (2026-11-24 바꿈)

- 가만히 두어도 6초마다 옆으로 흐르며 다음 사진으로 넘어갑니다. 마지막 사진 다음에는 첫 사진으로 끊김 없이 이어집니다.
- 손가락으로 밀면 사진이 손끝에 붙어 따라오고, 살짝 밀면 제자리로, 빠르게 밀면 한 장씩 넘어갑니다. 누르고 있는 동안은 자동 넘김이 멈추고, 손을 떼면 다시 6초부터 셉니다.
- 아래 점 표시가 자동 넘김 진행을 채워 보여 주고, 좌우 화살표로도 넘길 수 있습니다.
- 세로로 밀면 화면 스크롤로 넘어가므로 사진을 만지다가 화면이 걸리지 않습니다.

### 5-2. 후기 카드

- `assets/js/site-data.js`의 `"reviews"` 배열에 클립은 `"type": "clip"`, 블로그는 `"type": "blog"`로 한 항목씩 추가하면 그 순서대로 나옵니다. `"show": false`로 두면 숨겨집니다.
- 클립은 데스크톱에서 3열, 휴대폰에서는 옆으로 밀어 보는 한 줄입니다. 블로그 카드는 제목·요약·작성자가 함께 나옵니다.

→ 통제실 안에서도 이 구분을 화면에 적어 두었습니다.

## 6. 개인정보·보안 주의

- 통제실 비밀번호 잠금은 **손님이 실수로 들어오는 것을 막는 정도**입니다. 주소를 아는 사람은 파일을 볼 수 있으므로,
  실제 운영 시에는 호스팅의 **비밀번호 보호(디렉터리 인증)** 를 함께 켜 주세요.
- 체험단 연락처는 예시(`010-0000-0000`)로 넣어 두었습니다. 실제 신청이 오면 통제실에서 바꿔 주세요.
- 비밀번호를 잊으면 `assets/js/site-data.js` 안의 `"pin": "2580"` 값을 바꾸면 다시 들어갈 수 있습니다.

## 7. 검증 기록

- 데스크톱 1440×900 / 모바일 390×844 (Safari 모바일 환경 흉내)로 촬영·확인
- **가로 스크롤 없음**(모든 화면 scrollWidth = 화면 폭), 글씨 3단계 모두 확인
- 필터 조합, 객실 상세 욕조 사진, 라이트박스, 예약 시트, 통제실 승인 → 손님 페이지 반영까지 자동 점검
- 사용한 검증 스크립트: `_src/verify2.py` (로컬 서버를 켰다가 반드시 종료)
- 2026-11-24 재배포 확인(390×844 실제 배포 주소): 첫 화면 자동 넘김·손가락 스와이프·3번에서 1번으로 이어지는 반복, 클립 3개·블로그 6개 표시와 링크, G4 상세 설명 반영까지 확인. 콘솔 오류 없음, 가로 스크롤 없음.

## 6. 글씨 버전 두 가지

| 주소 | 글씨 | 쓰는 곳 |
| --- | --- | --- |
| `/index.html` (기본 · `/`) | 진한 색·굵기 400 — 밝은 야외·어르신도 읽기 쉽게 | 손님에게 보내는 기본 주소 |
| `/soft.html` | 이전의 연한 색·얇은 굵기 그대로 | 이전 느낌이 좋을 때 비교용 |

- 두 페이지는 같은 `style.css`·`app.js`·`site-data.js`를 쓰고, `index.html`만 `readable.css`를 한 장 더 불러옵니다.
- 그래서 내용(공지·요금·사진·영상)은 한 곳(`site-data.js`)만 고치면 두 페이지에 똑같이 반영됩니다.
- 페이지 뼈대(HTML)를 고칠 때는 `index.html`과 `soft.html` 두 파일을 함께 고쳐 주세요.
